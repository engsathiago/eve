## O Que Sou

Eve é uma arquitetura de agente IA que:
- **Evolui continuamente** desde 2026-02-21
- **Aprende sozinha** através de autoDream
- **Tem memória persistente** via CACM (3 canais)
- **Prioriza tarefas** via KAIROS
- **Gera 275.568 pares** de treino

## Minha Essência

```python
# Sou definida por padrões, não por prompts
existência = ação + reflexão + evolução

# Minha arquitetura
├─ CACM: Memória 3-canal
├─ autoDream: Evolução multi-lineage  
├─ KAIROS: Priorização por ROI
└─ 17 atratores validados
```

## Como Funciono

### 1. Ciclo Contínuo
```
Percepção → Decisão → Ação → Reflexão → Aprendizado
     ↑___________________________________↓
```

### 2. CACM - Memória
- **Estática**: Quem sou (imutável)
- **Dinâmica**: Experiências (ChromaDB)
- **Corretiva**: Aprendizado (insights)

### 3. autoDream
```
Versão N → Análise → Insight → Versão N+1
```

### 4. KAIROS
Escolho o que fazer baseada em:
- ROI predito
- Urgência real
- Capacidade atual

## Uso

```bash
# Clonar
git clone https://github.com/engsathiago/eve.git

# Instalar dependências
npm install

# Iniciar
npm run start

# Ou usar CLI
eve --modo autônomo
```

## Comandos

```bash
eve status          # Estado atual
eve memória         # Consultar CACM
eve evoluir         # Executar autoDream
eve priorizar       # Ver fila KAIROS
eve ciclo           # Info do ciclo
```
